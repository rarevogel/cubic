# Cubic Player

A modern take on [Open Cubic Player](https://github.com/mywave82/opencubicplayer) for the web and Android.
Same idea: a text-mode style music player with channel meters, a track view, a spectrum analyzer (LED bars,
mirror, curve and radial styles, with a scrolling spectrogram), a 10-band graphic equalizer with presets,
scopes, phase and note-dot displays and the spinning *Würfel*, with a refreshed look (VGA palette, VT323 display font,
optional CRT scanlines and four themes: VGA, DOS blue, Amber and Phosphor).

Everything runs locally in one self-contained HTML file (`dist/cubic.html`, about 3 MB). Nothing is uploaded.

## Formats

Every format Open Cubic Player plays, plus newer ones:

| Group | Formats | Engine |
|---|---|---|
| Tracker modules | MOD NST M15 STK WOW 669 AMF AMS C67 DBM DIGI DMF DSM DSYM DTM FAR FMT GDM ICE IMF IT J2B MDL MED MO3 MPTM MT2 MTM OKT PLM PSM PTM PT36 RTM S3M SFX SMOD STM STP STX SYMMOD ULT UMX XM XMF FC FC13 FC14 GT2 GTK GMC PUMA TCB UNIC MMS CBA ETX FTM; PowerPacker, MMCMP and XPK packed | libopenmpt |
| HivelyTracker | HVL AHX | HivelyTracker replayer |
| AdLib / OPL | A2M A2T ADL AMD BAM BMF CFF CMF D00 DFM DMO DRO DTM FMK GOT HSC HSP HSQ IMF IMS JBM KSM LAA LDS M MAD MDI MDY MKJ MSC MTK MTR MUS PIS PLX RAC RAD RAW RIX ROL SA2 SAT SCI SDB SNG SOP SQX WLF WM XAD XMS XSM, OPL VGM | AdPlug + Nuked OPL3 |
| Consoles | AY GBS GYM HES KSS NSF NSFE SAP SPC VGM VGZ | Game Music Emu |
| C64 / Atari ST / Spectrum | SID PSID RSID SNDH YM VTX PSG ASC PT2 PT3 STC TS, AY-3-8910 VGM | cawtooth |
| MIDI | MID MIDI RMI KAR SMF XMI, Doom MUS | libADLMIDI (OPL3, 79 banks) or TinySoundFont with your SF2 |
| Audio | WAV MP3 MP2 MP1 OGG OPUS FLAC M4A AAC ALAC WEBM QOA WV TTA APE MPC WMA AIFF CAF DSF DFF AC3 SPX | Web Audio + decoders |
| Containers | ZIP GZ TGZ TAR (also MDZ etc.), CUE sheets, M3U, PLS | fflate |

Companion files (KSM `insts.dat`, ROL/IMS `.bnk`, SCI `patch.003`, SNG `.ins`, …) are found automatically
when they are in the same folder or archive.

Not possible in a browser: CD audio (CDA). Online browsing works in the Android app for any HTTP directory
listing (Modland included); in a browser it only works for sites that allow cross-origin access.

## Using it

Open files, a folder or a ZIP (or drag them onto the window). Files are kept in the Library (IndexedDB)
between sessions unless you turn that off in Settings. Press `?` for the keyboard shortcuts; they follow
Open Cubic Player where they can (`C T A O B N W I` for the views, `1`–`0` to mute channels, F-keys for
volume, panning, balance, speed and pitch).

## Android

`android/` wraps the same page in a WebView (`https://cubic.local/`), adds a multi-select file picker, a
folder picker that streams files from the device without copying them, native fetching for online
browsing, and a media notification + MediaSession so playback continues in the background and responds to
headset and lock-screen buttons. Package `nl.rarevogel.cubic`, minSdk 24, targetSdk 35.

## Building

```sh
npm install
(cd engines && ./build.sh)          # optional: rebuild the .wasm engines (needs `pip install ziglang`)
python3 build.py                    # -> dist/cubic.html and android/assets/index.html
# Android (no Gradle): needs aapt2, javac, dx, zipalign, apksigner and an android.jar of API 29-34
ANDROID_JAR=... KEYSTORE_FILE=... KEYSTORE_PASSWORD=... KEY_ALIAS=... android/build.sh
```

The engines in `engines/` are compiled from AdPlug, libbinio, Game Music Emu, HivelyTracker, libADLMIDI,
TinySoundFont and libspeex with zig's clang to `wasm32-wasi`, behind one small C interface (`common.h`).
`web/worklet-src.js` hosts them and libopenmpt in a single AudioWorklet.

Tests: `node tests/play.js <files…>` loads each file headlessly and checks that audio comes out;
`node tests/shots.js <outdir> <files…>` takes screenshots of every view on desktop and phone.
No music files are included in this repository.
